actup · Version Manager for GitHub Actions

Action versions live inside every workflow file.

Nothing is rewritten until you ask.

.github/workflows/ci.yml
uses: actions/checkout @v4 → @v7
uses: actions/setup-go @v4 → @v7
uses: actions/cache @v3 → @v6 ⚠
IMPERATIVE CLI · LOCAL OR CI
$ actup

Like nvm for Node or fvm for Flutter.
